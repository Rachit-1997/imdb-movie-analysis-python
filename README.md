🎬 IMDB Movie Analysis Project

This project is a data analysis portfolio project where I explored and analyzed IMDB movie data using Python (Pandas, Matplotlib, Seaborn).
The dataset contains information about movies, their ratings, revenue, genres, directors, and other attributes.

The aim of this project was to practice exploratory data analysis (EDA), data visualization, and insight generation to build strong foundations for analyst roles.

📊 Key Steps in the Project

1.Data Loading & Cleaning
    Imported dataset into Pandas DataFrame
    Checked for missing values, duplicates, and data consistency
    
2.Exploratory Data Analysis (EDA)
    Summary statistics
    Genre distribution
    Correlation between rating, votes, and revenue
    
3.Data Visualization
    Bar plots, histograms, heatmaps, and scatter plots
    Insights on movie popularity, genre trends, and revenue patterns
    
4.Key Insights
    Higher rated movies often generate higher revenue, but not always
    Action and Adventure genres dominate in revenue
    Directors with consistent high ratings tend to attract more votes
    A strong correlation exists between vote count and revenue
